BlueprintPseudocode guide

Reading Blueprint pseudocode

The plugin turns a Blueprint into a text file for code review. These pages show how each kind of node becomes text, with the Blueprint graph beside the lines it produces.

Where the engines differ, the examples show 4.27's text. UE5 writes double where 4.27 has float, and some node names and pins differently: see File layout.
