Text format

Every text names its format in its first line. The format changes only in a minor release, and this page lists each change.

The number in the first line

Two texts of the same format print the same asset the same way, whichever release of the plugin made them. A new format comes only with a minor release, such as 1.1. A patch release, such as 1.0.1, leaves every text as it was.

When you compare texts that two releases made and their first lines differ, part of the difference is the format, not the Blueprint. That happens with texts kept in source control or pasted into a chat, scripts that compare exports over time, and teammates on different releases. A diff in P4V or in the editor is not affected: it converts both sides with the plugin you have.

In P4 Code Review, a new format converts each file again the next time a review shows it, so a comment on an open review can move to another line (Swarm setup).
