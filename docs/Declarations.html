BlueprintPseudocode guide

Variables and components

Variables, components and class defaults: what this Blueprint declares and what it changes from its parent. Names are written without spaces, so a variable called "Max Health" is MaxHealth everywhere.

Variables

One line each: type, name, default value, then flags in brackets. Variables come in the order the My Blueprint panel lists them: grouped under their category, the categories in the panel's order, the variables in the order you arranged them, and those in Default last. Event dispatchers have a section of their own.

FlagMeaning
InstanceEditableThe eye icon is open: editable per instance in the level
ReadOnlyBlueprint Read Only
FieldNotifyField Notify (UE5): MVVM and UMG bindings are told when it changes
ExposeOnSpawnShown as a pin on Spawn Actor
PrivateNot visible to child Blueprints
Replicated / RepNotify=FReplication, with the notify function if one is set
Condition=CReplication Condition, when it isn't None (OwnerOnly, InitialOnly, ...)
Transient, SaveGame, ConfigThe matching checkboxes in the details panel
 
// Combat
BP_Enemy* CurrentTarget = None  [Transient]
float MaxHealth = 100.0  [InstanceEditable, Replicated]
E_FireMode Mode = E_FireMode::Burst
S_WeaponStats Stats = (Damage=25.0,FireRate=0.1)
Array<BP_Enemy*> Targets = []

// Default
int Ammo = 30  [Replicated, Condition=OwnerOnly]
bool IsDead = False  [RepNotify=OnRep_IsDead]

Components and class defaults

Each added component shows its class, its name and what it's attached to, with the settings that differ from the component's own defaults under it. A component from the parent class appears only when this Blueprint changes it, as override inherited component. "Class defaults" lists the parent's properties that this Blueprint changes.

A changed member of a struct setting is one line, as a path: BodyInstance.WalkableSlopeOverride.WalkableSlopeAngle = 30.0. A struct the engine keeps as one value, such as a Vector, Rotator or Color, stays whole on its line, and so does a list.

Objects created inside a property (instanced, "edit inline" objects) are written out in braces with the settings that differ. Class {} means nothing differs.

component SceneComponent Root  attached to DefaultSceneRoot (inherited)
component StaticMeshComponent DoorMesh  attached to Root
    BodyInstance.WalkableSlopeOverride.WalkableSlopeAngle = 30.0
    RelativeLocation = (X=0.0,Y=10.0,Z=0.0)
    StaticMesh = StaticMesh'/Game/Enviro/Door/SM_Door.SM_Door'
override inherited component CharacterMesh0
    bCastDynamicShadow = False
    BodyInstance.CollisionProfileName = NoCollision
// ===== Class defaults (differ from Character) =====

AutoPossessPlayer = Player0
Behaviour = BP_PatrolBehaviour {
    Speed = 300.0
}
bReplicates = True
CharacterMovement = CharacterMovementComponent {
    MaxWalkSpeed = 900.0
}
PrimaryActorTick.bStartWithTickEnabled = False
Steps = [
    MoveStep {
        Distance = 100.0
    },
    WaitStep {}
]
