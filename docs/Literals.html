Literals

Values typed into pins, and how they read in the text.

Pin valueWritten asNotes
String"Hello"Quoted, with escapes, exactly as typed
NameFName("Spine")So a name is not read as a string. An empty one is FName("None")
TextNSLOCTEXT("Ns", "Key", "Hello")As the engine writes a text: INVTEXT("...") for a text with no key, LOCTABLE("/Game/UI/ST_Menu.ST_Menu", "Key") for a string table entry
Booleantrue / falseVariable defaults use the engine's True / False
Float2.0, 0.25Without the trailing zeros the engine saves
EnumECollisionChannel::VisibilityThe enum's name and the entry's display name
Asset or class/Game/Weapons/BP_Projectile.BP_Projectile_CThe full path, so a same-named asset elsewhere shows; empty is None
Struct(X=1.0,Y=2.0,Z=3.0)The engine's text format, whatever form the pin saved it in. A Transform's rotation is a quaternion, (X=0.0,Y=0.0,Z=0.0,W=1.0), except in a pin you typed it into, where it is the angles typed
Unset struct pin(Damage=10.0,FireRate=0.5)The struct's default value as the engine exports it, members that are zero left out; default where the plugin cannot know it
Array, Set, Map[], {}Empty unless wired; see Make Array. A variable's default reads [A,B], or {("a", 1),("b", 2)} for a map
SelfselfThe Self node
