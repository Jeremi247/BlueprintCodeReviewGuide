BlueprintPseudocode guide

String tables

A String Table asset is written as its namespace and its entries, under the same header as a Blueprint's.

Entries

Each entry is "key" = "text", sorted by key, not in the order the asset saved them. Keys and texts are quoted as a string literal is, so a line break in a text is \n.

An entry's developer note is the line note "..." under it, and its metadata is one Name = "value" line per item, sorted by name. An item with an empty value, such as a cleared comment, has no line. Assets saved by an engine without developer notes, 4.27 among them, have none.

string table ST_Golden
namespace "Golden"

"Farewell" = "Goodbye"
"Game Over" = "Try again"
    Comment = "Shown on death"
    Speaker = "Narrator"
"Greeting" = "Hello"
    note "Shown on the title screen"
    Comment = "Used by the HUD"
