# Blueprint Pseudocode

The guide and issue tracker for **Blueprint Pseudocode**, an Unreal Engine plugin that turns Blueprints, string tables and StateTrees into text you can review and diff: in P4V, in P4 Code Review (Swarm), or exported from the editor.

**[Get it on Fab](https://www.fab.com/listings/9716c2f7-67ba-416a-8d0a-b708323d7c8e)**, for Unreal Engine 4.27 and 5.8 on Windows.

**[Read the guide](https://jeremi247.github.io/BlueprintCodeReviewGuide/)**: how to get the text, and how each kind of node reads. The same guide ships with the plugin, as `Docs/Guide.html` in its folder.

## Report a bug or request a feature

[Open an issue](https://github.com/Jeremi247/BlueprintCodeReviewGuide/issues/new/choose). Look through the [open issues](https://github.com/Jeremi247/BlueprintCodeReviewGuide/issues) first: if yours is there, add a 👍 or a comment to it instead.

Issues are public. Paste only what you are free to share: cut a Blueprint's text down to the lines that show the problem, and rename anything confidential.

## This repository

`docs/` is the site, published from the plugin's own copy of the guide. A fix to a page is welcome as an issue; a pull request to `docs/` is overwritten by the next publish.
